## Story Breakdown Options

- **User-journey-based**: Follows first impression, review of research, review of evidence, contact, and ongoing editing. Chosen as the primary structure because it matches the visitor journey.
- **Feature-based**: Groups by navigation, gallery, contact, and template. Useful for implementation planning but less clear about reviewer goals.
- **Persona-based**: Groups all needs of one audience. Useful for audience comparison but would duplicate shared visitor needs.
- **Domain-based**: Groups research, entrepreneurship, academics, and community. Useful for content curation but less useful for navigation and accessibility requirements.
- **Hybrid**: Combines the research-led visitor journey with feature stories for accessibility, contact, and maintenance. Chosen to retain both audience value and implementation coverage without duplicating stories.
